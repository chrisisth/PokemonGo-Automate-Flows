This flow does battles agains Candela until you stop. 
It only uses fast attacks, so you need shadow pokemon with waterfall or smack down basically. 

1. **Start**: Press the volume down button on GBL screen (where you see your battle summary) to activate the flow. It'll open a window where you input the amount of seconds it should battle before starting the battle again.
If unsure press ok and see if preselected value works.

2. **Operation**: The flow will scroll down, tap on Candela and select the league. It will switch to your second party member immeadiatly at first. It will show a message when it expects the battle to be done. After that it waits a bit and then starts battling again.

3. **End**: You can stop the flow at any time by pressing the volume up button. To kill the flow, you need to manually stop it in the Automate app.

### Features

- **Cancel**: You can stop the flow at any time by pressing the volume up button.
- **Restart**: If you wish to restart the flow, simply press the volume down button again.

This flow is designed to work with the free version of the Automate app by LlamaLab.
